# Journal des versions — tefillat-tools

Chaque version nomme l'empreinte `sha256` de la norme de translittération
qu'elle porte. **Une norme modifiée exige une nouvelle version** : sans
changement de numéro, Claude Code ne livre pas la mise à jour.

## 1.1.0 — 2026-10-04

norme: 9586359a8904538e7d9e0fe55440e9f5b140730c12643237b23102067255ba53

- Trois règles arbitrées : le sheva sous la première de deux consonnes
  identiques est mobile (`Haleli`) ; `יָהּ` s'écrit `Yah` et se traduit « Yah » ;
  la majuscule va au premier mot de chaque phrase, déduit du sens.
